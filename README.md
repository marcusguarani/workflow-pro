# Workflow Pro - Sede x Obras

Protótipo profissional em PHP + MySQL com visual em Bootstrap, dashboard com gráficos e fluxo de demandas entre sede e obras.

## Recursos
- login com instalador web
- dashboard com gráficos analíticos
- métricas de SLA e produtividade
- cadastro e acompanhamento de demandas
- kanban operacional
- cadastro de usuários e setores
- histórico de movimentações

## Como instalar
1. Extraia o projeto em `C:\laragon\www\workflow-pro-v1`
2. Ajuste `config/config.php` se necessário
3. Acesse `http://localhost/workflow-pro-v1/public/install.php`
4. Clique em **Instalar sistema**
5. Depois acesse `http://localhost/workflow-pro-v1/public/`
